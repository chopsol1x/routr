# routr.fun

Noncustodial revenue routing on Solana: the routr.fun landing page with an interactive Revenue Router demo.

It's a static site: `index.html` plus icons, no build step. Host it on GitHub Pages (Settings → Pages → Deploy from branch → `main` / root), Vercel or Netlify.

The wallet connection, plan signing and payments are a clearly labelled demo; nothing is sent on-chain. Coin search uses DexScreener's public API from the browser.
